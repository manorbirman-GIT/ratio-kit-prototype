# Ratio Kit · concept prototype

A click-through concept for the Artlist AI Toolkit, made for an Artlist home assignment. Not an Artlist product.

**Try it:** https://manorbirman-git.github.io/ratio-kit-prototype/

Agencies deliver every ad in several ratios, and each client needs a different set. With Ratio Kit, each client project remembers its ratios, and one Generate makes all of them, with a 5-second check before anything is sent.

- Mocked data: nothing is generated or charged, and no usage data is collected.
- Built with Claude as my coding partner: I defined the problem, the solution and what goes in, tested it and fixed what didn't work. Claude wrote the code.
- The usability-test version lives in [saved-ratios-prototype](https://github.com/manorbirman-GIT/saved-ratios-prototype).
